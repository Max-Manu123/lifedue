# LifeDue

LifeDue is a lightweight client-work organizer for freelancers and solopreneurs.

## MVP

- Landing page with no forced signup
- AI Quick Add prototype
- Today dashboard
- Tasks
- Clients
- Payments
- Simple AI Planner prototype
- Local persistence with localStorage
- Responsive mobile/desktop UI

## Run locally

```bash
npm install
npm run dev
```

This first MVP intentionally uses localStorage instead of authentication or a backend so the core workflow can be validated quickly.
